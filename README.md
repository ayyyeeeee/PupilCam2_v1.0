# Pupil Cam2 双眼眼动仪 v1.0

这是 v0.2 的延续版本，保留双路 UVC、原生 Detector2D + pye3d、ROI、曝光、翻转、交换眼睛、三维视图与检测调试。旧版本不被覆盖。

## 本机启动

双击 `02_start.bat`。若提示缺少 runtime，先运行 `01_install.bat`。
程序打开后默认双眼检测开启。确认眼睛方向和 Eye 0/1 的实际对应；两个相同名字的设备没有可靠左右标签，换 USB 口后应重新确认。

## 拷贝到新电脑

适用目标：Windows 10/11、Intel/AMD 64 位。不是 macOS、Linux、ARM64 或 32 位通用包。

1. 把整个 `PupilCam2_v1.0` 文件夹复制到本地可写目录。名称、盘符、父目录均可改变，也支持中文及空格。不要只复制一个 .py，不要在 ZIP 预览中直接运行；避免 Program Files 等受保护位置。
2. 双击 `01_install.bat`。首次自动校验并解压离线 Python 和所有依赖，再运行软件自检。无需 Anaconda、系统 Python、网络或修改 PATH，也不安装虚拟环境。
3. 接入眼镜，按驱动向导操作。已找到两个正常 libusbK 父设备时不会更改驱动。否则输入 YES 打开有官方签名的 Zadig，接受管理员提示。
4. 只选 `Pupil Cam2 ID0`、USB ID **0C45 64AB**，且没有 Interface 0/1、MI_00/MI_01 后缀。目标驱动选 **libusbK**。对两个对应父设备分别安装/替换。不要选择 USB Hub、键鼠、其他设备，不要选 Filter Driver 或 WCID 操作。
5. 如果列表没有父设备，检查 Options → List All Devices，并取消 Ignore Hubs or Composite Parents。这会显示其他重要设备，务必核对 ID。附带的 `drivers/PupilCam2.cfg` 可从 Device → Load Preset Device 加载，仍须核对实际设备。
6. 关闭 Zadig，重新插拔眼镜。先关闭所有摄像头程序，再运行 `04_camera_check.bat`，必须显示两个 400×400 流通过，最后运行 `02_start.bat`。

驱动说明：原电脑可用的是 libusbK 3.0.7；官方 Zadig 2.9 提供 3.1.0。新电脑安装会生成该设备专用的目录/证书，需用户确认，不能把原电脑的本地信任证书盲目移植。此包不关闭签名强制、Secure Boot 或杀毒功能。企业策略或系统安全策略阻止时，请停止并让管理员处理。新电脑驱动兼容性仍须第 6 步验证，不能承诺任何电脑无条件成功。

软件自检不等于摄像头通过，也不等于眼动准确率通过。`05_driver_setup.bat` 可单独重开驱动向导。

## 追踪变化与准确率边界

- 保留固定大小图像与状态区，文字长短不应再带动 Eye 1 抖动。
- 原生检测失败时，周期性改变搜索参数、扫描完整 ROI，并用暗区域轮廓提供局部搜索位置。轮廓只是搜索提示，最终仍需原生检测和当前图像边界证据确认。
- 强边界证据下允许侧视瞳孔面积变化，不再一概把透视变扁当成眨眼。弱证据仍被拒绝。
- 眨眼、遮挡、断流立即暂停有效视线；恢复须连续确认。辅助轮廓只显示，不冒充测量，也不参与三维建模。
- 三维输出至少等待 5 秒和 60 个有效二维观测，并继续要求当前检测/模型置信度通过。等得久不能补回看不见的瞳孔。
- 交换眼睛会重置旧坐标系中的三维模型；导出保存原始有效二维测量，不把平滑显示值当原始数据。

录像里摄像头非常侧视，某些眼位瞳孔仅剩窄条，部分眼位完全被遮住。算法不能从完全不可见图像中恢复真实瞳孔。优先调整摄像头角度/位置，让看中间及上下左右时瞳孔尽量完整；不要求正对，但要减少极端侧视。

先保持默认检测范围 10–150，不要为了圆形瞳孔把下限调得过大。曝光从默认值开始，以瞳孔与虹膜边缘可见为准；不是越亮越好。ROI 要包括所有注视方向的眼睛区域，尽量排除大块皮肤与边缘阴影，但不能裁掉转动后的瞳孔。

Gaze View 是手动几何参数下的示意视图，**未经屏幕标定，不是准确屏幕落点/注视距离**。本版不导出未经标定的屏幕坐标，也不提供“准确率百分比”承诺。

## 小体积数据导出

点击 `Start / Stop export`，默认每眼最高 20 Hz，可选 10/20/30。再次点击或正常退出会关闭文件。`Mark event` 可标记某次注视/动作。频率是上限，不是重采样保证：30 fps 输入在 20 Hz 上限下通常会留下约 15 Hz；需要保留全部已处理帧时选 30。

保存到本目录 `data/recordings/日期时间_随机编号/`：

- `samples.csv`：时间、眼编号、帧号、状态、二维/三维有效标志、置信度、瞳孔中心/椭圆、有效相机坐标系视线单位向量。
- `events.csv`：所有有效性变化、参数变化、手动标记、停止事件；短于采样间隔的丢失不会静默消失。
- `metadata.json`：版本、相机 UID、参数、翻转和坐标约定、频率上限。
- `summary.json`：时长与有效样本计数。计数比率是可用率，不是准确率。

CSV 为 UTF-8 BOM，可用 Excel、Python 等读取。无效坐标留空，不填 0、不重复旧值、不插值。对视线分析必须先筛 `gaze_valid=1`；仅分析二维时筛 `pupil_valid=1`。Eye 0/1 使用各自帧到达时间，不假装硬件同步。行时间戳单位秒，来自主机单调时钟，不是传感器曝光时刻。

瞳孔坐标来自翻转后的眼相机图像：x 向右、y 向下，椭圆轴为直径像素；视线向量属于该眼相机坐标系，不是屏幕/世界坐标。`events.csv` 中的参数事件要与样本一起使用，不要混合不同翻转/ROI/曝光设置直接统计。

普通导出不存视频或每帧图像，通常仅数十 MB/小时以内，具体随频率/有效率变化。30 Hz 摄像头加降采样不适合高频扫视速度、微眼跳等研究；不要把本数据用于医疗诊断或安全控制。

## 下一轮最有帮助的测试

1. 固定头部，看中间/左/右/上/下，各 3–5 秒，每次切换点击 Mark event；再正常眨眼数次、闭眼约 1 秒再睁开。
2. 保存这次导出文件夹，并附对应短屏幕录像；如需要衡量屏幕准确率，还必须给出已知注视目标位置，当前仅凭眼睛录像不能计算角度误差。
3. 瞳孔明显可见却丢失时，打开 Detection Debug，保存 Debug Pack。这会额外保存少量原始图像到 `data/debug`，比带绘制标记的录屏更适合查算法问题；此操作不是日常连续导出。

## 文件与维护

`app/pupil_tracker.py` 为主程序，`recording.py` 为导出模块；`runtime.zip` 为离线环境，`runtime.sha256` 用于完整性校验。`requirements.txt` 锁定原方案所需库的兼容版本。运行时保留了 Python 及依赖自身的许可证，驱动工具及源码在 drivers。

运行环境固定 Python 3.10.11，以适配现有 cp310 Windows 二进制库，不宣称这是最新安全版本；不要把它当通用联网 Python 环境。以后升级须连同原生库一起重新验证。

本版本不改动旧版程序/配置/驱动。数据默认留在本文件夹，移动时请连同 data 保留；分享软件给别人前不要把个人眼图和实验数据一并发出。异常强制断电可能损失缓冲末尾约 1 秒，缺少 summary.json 代表应检查是否异常终止。

参考：[Pupil Labs 检测与最佳实践](https://docs.pupil-labs.com/core/best-practices/)、[pye3d 原理](https://docs.pupil-labs.com/core/developer/pye3d/)、[Zadig 官方说明](https://zadig.akeo.ie/)、[驱动配置指南](https://github.com/pbatard/libwdi/wiki/Zadig)。
